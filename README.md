# TaskFlow

Aplicativo mobile de gerenciamento de tarefas desenvolvido com React Native e Expo.

## Funcionalidades

- Visualização de tarefas.
- Cadastro de novas tarefas.
- Definição de prioridade.
- Filtro por tarefas pendentes e concluídas.
- Marcação de tarefas como concluídas.
- Visualização dos detalhes de cada tarefa.

## Tecnologias utilizadas

- React Native
- Expo SDK 54
- JavaScript
- React Navigation
- useState e useEffect

## Estrutura do projeto

- `components/`: componentes reutilizáveis.
- `screens/`: telas do aplicativo.
- `data/`: dados iniciais das tarefas.
- `styles/`: configurações visuais.

## Como executar

1. Instale as dependências com `npm install`.
2. Execute `npx expo start`.
3. Abra o aplicativo pelo Expo Go ou emulador compatível.
